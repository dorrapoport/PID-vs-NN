# PID מול רשת נוירונים

אתר אינטראקטיבי להרצאה של חמש דקות: איך בקר PID מייצב רחפן, איך מאמנים רשת נוירונים לבחור את המקדמים שלו או להחליף אותו, ומה כל גישה עולה בחשמל, במשקל ובזמן טיסה.

כל ההדגמות הן סימולציה של ציר אחד שרצה בדפדפן. אין שרת ואין תלויות מלבד Three.js.

## תחנות

0. פתיחה
1. האתגר: מנסים לייצב ביד
2. הלולאה: מודדים, מחשבים, מתקנים
3. מעבדת PID
4. רשת מכווננת PID: איסוף דוגמאות, אימון בירידה בגרדיאנט, טיסה
5. רשת לומדת: 240 רחפנים מתאמנים במקביל
6. המחיר על הרחפן: שבב, הספק, משקל וזמן טיסה
7. השוואה
8. סיכום ומקורות

מקשים: חצים או רווח בין תחנות, 0 עד 8 קפיצה לתחנה, N הערות למרצה, P השהיה, F מסך מלא.

## מבנה

- `site/src/head.html`: עיצוב ומבנה העמוד
- `site/src/core.js`: הסימולציה והרשתות, בלי DOM
- `site/src/app.js`: ממשק ובמה תלת-ממדית
- `site/build.sh`: בונה את `site/index.html` (עותק עצמאי שעובד גם בלי אינטרנט) ואת `site/page.html`

אחרי עריכה ב-`site/src/` מריצים `sh site/build.sh`. כל דחיפה ל-`main` בונה את האתר ומעדכנת את הענף `gh-pages`, שממנו GitHub Pages מגיש אותו.
